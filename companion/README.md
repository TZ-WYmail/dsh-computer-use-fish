# DSH 鲸鱼娘桌宠（首版）

插件配置：`companionEnabled` 开关，`companionSize`（200–420），`companionReducedMotion` 减少动画。启动后 `dsh-fish hide` 隐藏、`dsh-fish show` 显示、`dsh-fish status` 查看状态。显示开关不会暂停电脑操作；停止任务请使用 Harness 的任务取消。

依赖当前 Linux 图形会话、XWayland、Python 3 的 GTK3/PyGObject/Cairo；无需更换桌面。透明窗口不接受焦点、鼠标穿透，截图前隐藏，工具结果区分确认与待确认。仅传递工具名、状态与目标几何，不传递输入内容或截图。

当前验证范围为 GNOME Wayland 单屏、200% 缩放。无法可靠校准的多屏组合回到角落，不猜测目标位置。AX 元素缺少坐标时跟随窗口边缘；已知像素坐标时显示轻量目标提示。12 种工具各有至少 3 个动画候选，复用 15 段现有角色动画，尚未逐工具绘制独立素材。

## fish.2：奔跑与接触动作

新增 `run`（奔跑）、`tap`（敲击）和 `wave`（挥手）三段上游素材。移动采用连续路径、朝向翻转和三档步态起伏；拍击采用角色原素材中的完整抬手、前拍、收手姿势和轻微身体回弹。双击显示两拍，右键增加菜单手势，拖拽先去起点接住再沿路径移动，滚动显示划动提示。

动作由宿主和渲染器握手同步：approach → ready → 目标复核 → dispatch → settle/cancel。点击只由宿主调用驱动，动画进程不执行输入。光圈代表投递时刻，最终成功仍依赖驱动结果和回读。驱动明确拒绝后台投递时终止该轮表演，批准后再进行前台尝试。

角色代替本 DSH 会话的虚拟光标；用户自己的鼠标保持可用。隐藏、失联或动画握手超时恢复普通虚拟光标。每次表演最多等待 2.1 秒，超时直接退回原工具路径。无法定位控件时只跑到窗口旁，保留普通指针，不伪造拍击位置。多显示器仍保守回角落。

`DSH_FISH_DIAGNOSTICS` 可指定调试状态文件，只写角色位置、状态和动作时间戳；默认不生成。`preview_gesture.py` 使用实际渲染方法生成隔离动画预览，不读取桌面内容。

GNOME 驱动在输入中可能再次绘制箭头；本版在投递后再次收起，真实结果截图已验证无箭头残留，投递过程仍可能短暂闪现。

## fish.3：角色一体拍击修正

已移除所有外接手套、延长手臂和连接线。鱼娘靠近目标，使原素材中的双手区域与目标对齐；完整角色姿势按抬手、前拍、收手切换，手臂始终属于原角色画面。仅在接触时显示小范围淡光圈，不再另画肢体。边缘位置以完整人物可见为优先，可能无法把自身手部精确移至屏幕最边缘。

## fish.4：每种操作的三个变体

12 类操作各有三个命名候选，见 `behavior.json` 的 tools.variants；指针动作的姿态与节奏参数见 gestures。同一种操作循环轮换、避免连续重复；同一 actionId 在后台到前台重试间保持同一候选，不改变真实点击次数。角色始终使用完整素材，当前变化通过现成片段、完整角色姿势、身体前倾与回弹幅度、抬手节奏组合完成，尚不是 36 段独立新绘制动画。

## fish.5：跳起拍击

单击首个候选改为“跳起拍下”：全身蓄力压低、约 84 个逻辑像素的抛物线跳起、落回目标、拍击与轻微回弹。落地到位后才通知宿主发送一次点击。普通轻按、探身点按继续轮换。仅完整角色发生位移，未添加任何外接肢体。减少动画模式及顶部没有跳跃空间时退回普通拍击，保证画面可见；动画到位等待上限调为 2.1 秒。

## fish.6：首批丰富动作落地

单击：保留跳起拍下，新增真实转身侧拍和冲近点按；双击：左右手交替、跳落连拍、转身连按；右键：轻敲探头、侧身点按、蹲下戳按。拖拽：抱住倒退搬、侧身用力推、鱼尾勾住拉；滚动：划水翻页、全身推页、鱼尾带页。人物全程使用完整画面，没有外接肢体。

新增 8 张 image_gen 生成的完整角色关键姿势及 8 段固定来源的原动画；生成姿势的原 PNG 保留真实透明通道，未拆解肢体。`assets/poses.json` 保存文件哈希、完整提示词、参考图与接触锚点，`assets/sources.json` 保存上游动画来源。角色授权与署名要求继续适用，AI 辅助衍生素材也作为非商业社区角色资源使用。

查看屏幕可举望远镜，放大可举放大镜；输入增加原生写代码／记录动作，等待可抱饭碗或在超过 8 秒后小憩。完成反馈可小跳、转身或吃饭。部分方案仍复用已有片段，未声称 36 个候选都是独立新绘制的连续动画。

候选池按操作独立抽取，首轮 0→1→2，后续公平洗牌并避免相邻重复；一次操作在前台重试前后保留同一选择。滚动方向仅作为枚举发送，不传输入内容。小影子和接触圈只表明动作过程，成功仍由操作结果决定。
